"""
mel_filterbank_from_scratch.py

Author: Mayank Jindal

Purpose:
--------
This module explains and implements Mel scaling and the Mel
filterbank from scratch. It transforms a linear-frequency
spectrogram (FFT bins) into a perceptually-scaled Mel
representation suitable for speech processing.

Overview:
---------
1. Human hearing does NOT perceive frequency linearly.
   Low frequencies are perceived with higher resolution,
   while high frequencies are perceived more coarsely.

2. The Mel scale approximates this perceptual behavior using
   a logarithmic mapping:
       mel = 2595 * log10(1 + f/700)

3. The process consists of:
   - Mapping Hz → Mel
   - Creating equally spaced points in Mel space
   - Converting Mel points back to Hz
   - Mapping those Hz values to FFT bin indices
   - Constructing triangular filter banks
   - Using the filterbank to compress FFT bins into Mel bands

------------------------------------------------------------------

Conceptual Foundation:
----------------------

Raw FFT output:
---------------
After STFT, each frame produces N frequency bins.
For window_size = 200:

    Δf = Fs / N = 1000 / 200 = 5 Hz
    Positive bins = 100 (0 to 99)

These bins are LINEAR in frequency:
0, 5, 10, 15, ..., 495 Hz

But human hearing is approximately LOGARITHMIC.

------------------------------------------------------------------

Mel Scale:
----------

The Mel scale warps frequency so that equal distances
in Mel correspond to equal perceived pitch differences.

Formula:
    mel = 2595 * log10(1 + f/700)

Inverse:
    f = 700 * (10^(mel/2595) - 1)

Properties:
-----------
• Low frequencies expand.
• High frequencies compress.
• Equal spacing in Mel → unequal spacing in Hz.

------------------------------------------------------------------

Mel Filterbank Construction:
-----------------------------

Step 1: Define Mel Range
------------------------
Compute:
    mel_min = Mel(0 Hz)
    mel_max = Mel(Nyquist)

This defines perceptual frequency bounds.

Step 2: Generate Mel Points
---------------------------
If num_filters = 20,
we generate num_filters + 2 Mel points.

Reason:
Each triangular filter requires:
    left boundary
    center
    right boundary

For 20 filters:
    22 Mel points are required.

These are equally spaced in Mel space using linspace.

Step 3: Convert Back to Hz
--------------------------
Mel points are converted back to Hz.
Because Mel spacing is logarithmic,
the resulting Hz spacing is:

• Dense at low frequencies
• Sparse at high frequencies

This automatically produces perceptual compression.

Step 4: Map Hz to FFT Bins
--------------------------
FFT bins are spaced by:

    Δf = Fs / window_size

So bin index is:

    bin_index = round(hz_point / Δf)

These indices define the boundaries for triangular filters.

Clipping is applied:
    np.clip(bin_points, 0, positive_bins - 1)

to prevent indexing errors.

------------------------------------------------------------------

Triangular Filter Design:
-------------------------

Each filter i uses three bin points:

    left   = bin_points[i]
    center = bin_points[i+1]
    right  = bin_points[i+2]

Filter shape:

• From left → center:
      linear rise 0 → 1
      (j - left) / (center - left)

• From center → right:
      linear fall 1 → 0
      (right - j) / (right - center)

All other bins = 0.

These triangles overlap smoothly.

------------------------------------------------------------------

Why Triangular Filters?
-----------------------

If we used hard bands:
    abrupt jumps occur when frequency shifts slightly.

Triangular filters:
    - Provide smooth transitions
    - Share energy across neighboring bands
    - Improve stability
    - Reduce sensitivity to small frequency shifts

------------------------------------------------------------------

Mel Filterbank Matrix:
----------------------

Shape:
    (num_filters, positive_bins)

Example:
    (20, 100)

Rows:
    Individual Mel filters (perceptual bands)

Columns:
    FFT frequency bins

Each element represents:
    How strongly a frequency bin contributes
    to a particular Mel band.

This matrix acts as a weighted grouping system.

------------------------------------------------------------------

Applying the Filterbank:
------------------------

Given:
    power_spectrum (magnitude squared of FFT)

Mel energies are computed as:

    mel_energy = mel_filterbank × power_spectrum

This compresses:
    100 FFT bins → 20 perceptual energy bands

Dimensionality reduction + perceptual alignment.

------------------------------------------------------------------

Why Power Spectrum (magnitude²)?
--------------------------------

Speech perception relates to energy distribution,
not raw amplitude.

Energy = magnitude²

Using power:
    - Reflects physical signal energy
    - Produces stable perceptual features

------------------------------------------------------------------

Perceptual Effect:
------------------

Low frequency region:
    - Narrow filters
    - Higher resolution

High frequency region:
    - Wide filters
    - Coarse grouping

This matches human auditory resolution.

------------------------------------------------------------------

Complete Speech Processing Context:
------------------------------------

Full traditional speech recognition pipeline:

    Audio
      ↓
    STFT
      ↓
    Mel Filterbank
      ↓
    Log compression
      ↓
    DCT
      ↓
    MFCC
      ↓
    Acoustic Model

You have implemented the Mel Filterbank stage manually.

----------------------------------------------------------- -------

Advantages of Mel Scaling:
---------------------------

• Reduces dimensionality
• Matches human perception
• Reduces noise sensitivity
• Emphasizes important speech formants
• Improves machine learning performance

------------------------------------------------------------------

If Mel Scaling Was Not Used:
----------------------------

Using raw FFT would:
    - Over-represent high-frequency detail
    - Increase noise sensitivity
    - Provide less perceptually meaningful features
    - Increase model complexity

------------------------------------------------------------------

Key Insight:
------------

FFT uses a linear frequency ruler.
Mel scaling changes the ruler to a perceptual ruler.

We are not analyzing physics alone.
We are preparing data for human speech recognition.

------------------------------------------------------------------

Edge Case Awareness:
--------------------

If center == left or right == center:
    Division by zero occurs.
    Such filters must be skipped or guarded.

If bin_points exceed valid FFT range:
    They must be clipped.

------------------------------------------------------------------

Dimensional Understanding:
--------------------------

Before Mel:
    100 linear bins per frame

After Mel:
    20 perceptual bands per frame

Compression ratio:
    5:1 (in this example)

------------------------------------------------------------------

Deep Concept:
-------------

Mel scaling does not change time.
It reshapes frequency sampling density.

Equal spacing in Mel space →
Perceptually uniform representation.

------------------------------------------------------------------

Conclusion:
-----------

Mel filterbanks are a perceptually motivated
frequency compression mechanism.

They transform linear FFT energy into
human-hearing-aligned feature representations.

This is the foundational step for
MFCC extraction and speech recognition systems.
