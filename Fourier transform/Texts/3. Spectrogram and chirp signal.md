"""
stft_tradeoff_experiment.py

Author: Mayank Jindal
Purpose:
--------
This script demonstrates the Short-Time Fourier Transform (STFT)
and the time–frequency tradeoff using a linear chirp signal.

Overview:
---------
1. A linear chirp signal is generated whose frequency increases
   smoothly from 10 Hz to 150 Hz over 2 seconds.

2. The chirp is created properly using phase integration:
   - Frequency is defined as a function of time.
   - Phase is computed as the cumulative integral of frequency.
   - The signal is generated as sin(phase).

3. A spectrogram is computed manually (from scratch):
   - The signal is divided into overlapping windows.
   - A Hanning window is applied to reduce spectral leakage.
   - FFT is computed for each window.
   - Only positive frequencies are retained.
   - Magnitudes are stacked to form a 2D time-frequency matrix.
   - The matrix is transposed for correct visualization.

4. The spectrogram is plotted using matplotlib.

Key Concepts Demonstrated:
--------------------------
• Linear Chirp:
  Frequency increases linearly with time:
      f(t) = f_start + (f_end - f_start)/T * t

• Phase Computation:
  Since sine depends on phase (not directly on frequency),
  phase must be computed as:
      phase = 2π * ∫ f(t) dt
  Numerically approximated using:
      np.cumsum(f_t) * dt

• STFT (Short-Time Fourier Transform):
  The signal is analyzed in short windows to observe
  how frequency content evolves over time.

• Frequency Resolution:
      Δf = Fs / N
  where:
      Fs = sampling frequency
      N  = window size

• Time–Frequency Tradeoff:
  - Larger window → better frequency resolution,
                    poorer time resolution.
  - Smaller window → better time resolution,
                     poorer frequency resolution.

Expected Output:
----------------
The spectrogram should display a diagonal line rising
from ~10 Hz to ~150 Hz, representing the increasing
frequency of the chirp.

By modifying window_size (e.g., 50, 200, 400),
the time–frequency tradeoff can be visually observed.
"""
"""


Observations on Time–Frequency Tradeoff:

Frequency resolution is given by:
    Δf = Fs / N

Increasing window_size (N):
    - Reduces Δf → sharper frequency precision
    - Increases window duration → poorer time localization

Decreasing window_size:
    - Improves time tracking
    - Broadens frequency bins (poorer frequency precision)

This limitation is fundamental and related to the
time–frequency uncertainty principle.
