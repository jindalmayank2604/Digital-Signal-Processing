```
~600
```

Wo **signal amplitude nahi tha**.

Wo tha:

\[
\frac{N}{2} \times A
\]

Example:

If:

- N = 1000
- A = 1.2 approx

Then:

\[
\frac{1000}{2} \times 1.2 = 600
\]

So 600 is not "strength".  
It is FFT-scaled value.
